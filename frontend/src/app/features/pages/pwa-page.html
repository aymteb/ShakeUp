Sur l’écran d’accueil, sans App Store

ShakeUp côté élève est une PWA : vous ouvrez le lien envoyé par votre coach, vous vous connectez, vous ajoutez l’icône à l’écran d’accueil. Pas de file d’attente sur les stores.

Capture installation — à venir

Pourquoi ça compte

  • Accès immédiat après invitation coach.
  • Même expérience web / téléphone, un seul front élève à maintenir.
  • Service worker Angular pour le socle installable (build production).

Architecture exposée

Quatre briques : landing + PWA élève, back-office coach, API Spring, Postgres. Domaines séparés en prod (vitrine, app, pro, api) — le même découpage qu’en local (:4200 / :4300 / :8080).
